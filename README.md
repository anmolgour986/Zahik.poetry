# 🌙 Poet & Visionary

> *“A poem is not written — it is excavated.”*

A minimalist, elegant literary portfolio website crafted to reflect the depth, silence, and beauty of poetry.

## ✨ Live Website

LIVE WEBSITE : https://poeticzai.netlify.app/

---

## 📖 About the Project

This project is a **personal portfolio website** for a poet, designed with a refined aesthetic inspired by:

* Classical Urdu literature
* Minimalist design philosophy
* Soft parchment tones & gold accents

It creates an immersive reading experience rather than a typical website.

---

## 🎨 Features

* 🖋️ Elegant typography (Cinzel, Cormorant Garamond, Urdu font)
* 🌫️ Smooth animations & transitions
* 📜 Poetry section with bilingual verses (English + Urdu)
* 🧭 Timeline of literary journey
* 📚 Works / publications showcase
* 📱 Fully responsive design
* 🎭 Artistic UI with subtle textures and ornaments

---

## 🛠️ Built With

* HTML5
* CSS3 (Custom styling, no frameworks)
* Google Fonts


---

## 🚀 Deployment

This website is deployed using **GitHub Pages**.

To deploy your own version:

1. Fork or clone the repository
2. Upload your files
3. Go to **Settings → Pages**
4. Select branch: `main`
5. Your site will be live instantly
